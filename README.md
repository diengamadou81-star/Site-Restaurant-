## 📁 Structure du projet

```
le-gout-de-mbour/
├── index.html       # Site complet (HTML + CSS + JS)

└── README.md        # Ce fichier
```

---

## 🚀 Déploiement

### Option 1 — Via Vercel CLI (terminal)

```bash
# 1. Installer Vercel CLI
npm install -g vercel

# 2. Se placer dans le dossier du projet
cd le-gout-de-mbour

# 3. Déployer
vercel --prod
```

Suivez les instructions à l'écran (connexion par email ou GitHub).  
Votre site sera en ligne sur une URL du type : `le-gout-de-mbour.vercel.app`

---

### Option 2 — Via GitHub + Vercel (interface web)

1. Créez un repo GitHub et uploadez les fichiers (`index.html`, `vercel.json`, `README.md`)
2. Allez sur [vercel.com](https://vercel.com) → **New Project**
3. Importez votre repo GitHub
4. Cliquez **Deploy** — c'est tout ✅

---

### Option 3 — Drag & Drop (le plus simple)

1. Allez sur [vercel.com/new](https://vercel.com/new)
2. Glissez-déposez votre **dossier entier** dans la zone indiquée
3. Vercel détecte automatiquement le site statique et déploie

---

## 🌐 Domaine personnalisé (optionnel)

Après déploiement sur Vercel :

1. Allez dans **Settings → Domains**
2. Ajoutez votre domaine (ex: `legoutdembour.sn`)
3. Configurez les DNS chez votre registrar :
   - **Type A** → `76.76.21.21`
   - **CNAME** → `cname.vercel-dns.com`
